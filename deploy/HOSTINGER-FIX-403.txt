HOSTINGER — FIX 403 FORBIDDEN
=============================

The 403 page you see is from Apache/LiteSpeed — Django is NOT running yet.

STEP 1 — Create the Python app in hPanel (required)
--------------------------------------------------
Websites → Advanced → Python → Create application

  Application URL:     https://app.gayatritechsolutions.com
  Python version:      3.10+ (3.12 if available)

Then use ONE of these two setups:

SETUP A (recommended — document root = public/)
  Application root:    folder that contains manage.py
  Public directory:  public
  Startup file:      public/passenger_wsgi.py
  Entry point:       application

SETUP B (document root = project folder)
  Application root:    folder that contains manage.py
  Startup file:        passenger_wsgi.py
  Entry point:         application

Click SAVE, then RESTART the Python application.

STEP 2 — Upload ALL project files
---------------------------------
Upload the complete folder (not only manage.py):

  manage.py
  passenger_wsgi.py
  .htaccess
  .env
  requirements.txt
  public/passenger_wsgi.py
  public/.htaccess
  public/health.txt
  config/
  core/
  api/
  templates/
  static/

STEP 3 — Install & setup (Hostinger Terminal)
---------------------------------------------
  cd /path/to/your/app
  pip install -r requirements.txt
  python manage.py setup_hosting

STEP 4 — Test (in this order)
-----------------------------
  https://app.gayatritechsolutions.com/health.txt
    → should show: ok
    → if 403 here: subdomain is NOT pointing to public/ OR Python app not linked

  https://app.gayatritechsolutions.com/health/
    → should show: Vaaradhi Trust Django OK
    → if health.txt works but this fails: run setup_hosting again

  https://app.gayatritechsolutions.com/
    → full website

NEVER open in browser:
  /manage.py
  /passenger_wsgi.py

COMMON MISTAKES
----------------
1. Files uploaded to public_html of main site instead of Python app folder
2. Python app created but subdomain still points to empty public_html
3. Missing .htaccess or public/passenger_wsgi.py after upload
4. Forgot to click Restart after changing Python settings

If still 403 after STEP 1–3, send a screenshot of:
  hPanel → Python → your app (root, startup file, public directory, URL)
